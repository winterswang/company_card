## 核心叙事张力

2 亿元的无形资产，撑起了 1890 亿元的市值——泡泡玛特（09992.HK）资产负债表上价值最高的"核心资产"几乎不在账上。这份研究要回答的是一个看似简单却撬动估值判断的问题：那 1888 亿的差额，到底去了哪里？去了多少？能持续多久？

我们将用泡泡玛特真实的 2025 年报数据，定量验证"自创型品牌溢价者账面几乎不体现核心资产、但每元费用化投入高杠杆沉淀为表外 IP/品牌"这一框架命题，并回答它对泡泡玛特究竟是"结构性成立"还是"LABUBU 峰值通胀"。

## 一、2 亿无形资产与 1890 亿市值：泡泡玛特的核心资产去了哪里？

### 1.1 一个反常的资产负债表

把泡泡玛特 2025 年报（[S] HKEX 09992，2026-03-25 公告）摊开，会看到一组令人困惑的数字：

- 营业收入 371.2 亿人民币（+184.7% [S] 年报 tracker）

- 归母净利润 127.76 亿人民币，EPS 9.61 元（[S] 年报反推）

- 总市值约 2050 亿港元，折合 ~1890 亿人民币（市价 ~154 港元 × 总股本 ~13.3 亿股，[S] 市场数据）

- 而无形资产账面价值仅 2.09 亿人民币（同比净增 0.74 亿，[S] 年报）

也就是说，支撑千亿市值的核心资产——LABUBU、SKULLPANDA、Hirono、Molly、DIMOO 等 IP——在账面上几乎"消失"了。年报披露的 IP 矩阵呈现"一超多强"格局：THE MONSTERS（LABUBU 系列）以 141.6 亿元占营收 38.1% 居首，其后是 SKULLPANDA 9.5%、CRYBABY 7.9%、MOLLY 7.8%、DIMOO 7.5%、星星人 5.5%；过亿营收 IP 从 2020 年的 4 个增长到 2025 年的 17 个（[S] 年报 IP tracker）。

### 1.3 双口径框架：丈量差额的两把尺子

账面 2 亿、表外 987 亿，差额去哪了？要回答这个问题，单一会计数字不够，我们需要两把"尺子"：

- 会计口径（支出资产化率） = 记录无形资产增量 ÷ 费用化支出。它问的是：会计准则让多少投入"沉淀"进了资产负债表？

- 经济口径（支出资产化率） = 表外 IP/品牌价值（EPV−AV 代理）÷ 累计费用化投入。它问的是：每一元费用化投入，在真实经济中沉淀了多少可创造价值的资产？

前者给出"账面假象"的成因，后者给出"表外真相"的规模。下面两章将分别用这两把尺子丈量同一个泡泡玛特。

桥接：会计口径先回答"为什么账上只有 2 亿"——这把尺子会告诉我们，是会计准则制造了一场"计量假象"。

## 二、会计口径 0.78%：IAS 38 制造的计量假象

### 2.1 一个 0.78% 的数字，精确印证了"自创资产不入账"

用会计口径尺子丈量，结果一目了然：

- 分子：2025 年无形资产净增 0.74 亿 RMB（HKD 原币口径 0.85 亿，取自原币财报而非 FX 换算，[S] 年报）

- 分母：当期"经销及销售开支 80.82 亿 + 一般及行政开支 17.70 亿"= 合计 98.52 亿 RMB 全部当期费用化（HKD 原币 109.1 亿，[S] 年报）

会计口径 IP 资产化率 = 0.74 / 98.52 = 0.75%（RMB 口径）；HKD 原币口径 = 0.85 / 109.1 = 0.78%。两个口径偏差仅 0.03pp，落在 0.3pp 容差内（[S] 年报勾稽确认）。若把 PP&E 购置（9.85 亿 RMB）也算进分母，得到含 Capex 口径 7.0–7.3%（偏差 ≤0.3pp，[S] PPE 勾稽）——但即便如此，账面沉淀率仍极低。

### 2.2 准则之手：IAS 38 第 63–64 段的禁令

为什么会计口径低到几乎为零？答案在 IAS 38 内部产生无形资产准则（[S] cpc.gov.mo / ifrs.org）的第 63–64 段——它明确禁止将"内部产生的品牌"确认为无形资产入账。

直接后果是：泡泡玛特自创的全部 IP（Skullpanda / Hirono / LABUBU / CRYBABY 等），以及所有浮动分成性质的艺术家设计费，全部被费用化、自创部分资产化率 ≈ 0。年报确认（[S] 年报 + 招股书阅读备忘录），仅两类投入能进入资产负债表：

- 买断完整 IP（早年以一次性对价收购 Molly 的全部版权）；

- 固定保底授权费（不论销量都要支付的固定金额）。

按性质拆分费用结构更可见端倪（[S] 年报）：授权费 8.33 亿 + 设计服务费 0.86 亿 + 广告营销 11.94 亿 + 员工薪酬 22.52 亿（含设计/IP 团队）——全部当期费用化。连最"重资产"的门店扩张，也主要以"使用权资产"（租赁 27.91 亿 RMB）而非 PP&E（14.18 亿）的形式呈现，本质仍是轻资产运营。

### 2.3 结论：账面 2 亿是"计量假象"，不是经济真相

0.78% 这个数字不意味着泡泡玛特"没有资产"，而是说：在现行会计准则下，这家公司最值钱的资产结构性地无法进入资产负债表。账面 2 亿的无形资产，是 IAS 38 的一个计量假象。

桥接：会计口径告诉我们"表外"，但没告诉我们"表外有多少"。要回答后者，必须换用经济口径——丈量每花 1 元费用化投入，到底沉淀了多少表外价值。

## 三、经济口径 130–325%：每花 1 元费用化投入，沉淀了多少表外 IP 价值

### 3.1 一个 325% 的峰值，与一个 130% 的结构性下限

把 EPV − AV = 987 亿（表外特许经营权价值，[S] KB 估值）作为表外 IP 价值的代理分子，除以"累计费用化 IP/品牌建设支出"作为分母：

- 2020–2025 合计费用化支出 244 亿 RMB（[S/估算] westock 序列）

- 叠加 2010–2019 估算 60 亿（含约 20% 粗估）

- 累计分母 ≈ 304 亿 RMB

经济口径资产化率 ≈ 987 / 304 = 325%（[S/估算]）。这意味着：每花 1 元费用化投入，沉淀约 3.25 元的表外 IP/品牌价值。

但这个 325% 是"峰值上限"。敏感性分析显示，分母窗口的取法直接影响数值：若仅取 2020–25 累计分母（剔除 2010–19 粗估），则 987 / 244 = 404%——基数对峰值数值相当敏感（[计算] 对照）。

### 3.2 半衰期敏感性：从 325% 到 130%

325% 隐含了一个"IP 近永久"的乐观假设。现实里 IP 有衰减，引入衰减永续模型（经济资产化率 ∝ r/(r+ln2/T)，r=10%）做半衰期敏感性分析（[计算]）：

||||
|---|---|---|
|永续|325%（或 404%，按分母取法）|含 LABUBU 峰值溢价|
|15 年|222%|仍处任天堂–苹果梯队上端|
|8 年|174%|仍 >50%，梯位稳健|
|5 年|130%|接近结构性下限|
|T 年（极短）|<100%|跌破 100%，EPV 向 AV 回归|

剔除 LABUBU 峰值溢价后的结构性经济资产化率约 130–180%（对应半衰期约 5–8.6 年）（[S/B] 敏感性示意）。永续基准下的对标梯位为：茅台（500–1900%）> 泡泡玛特（325%）> 苹果（120%+）> 任天堂（100–500%）；按结构性调整后，泡泡玛特落入该梯队的下端。

### 3.3 镜像印证：EPV/AV = 5.13x，80.5% 经济价值在表外

经济口径 130–325% 的结论，得到 EPV/AV 比值的镜像印证：5.13x 意味着经济价值中仅 <20% 落在表内、80.5% 为表外特许权（[S] KB 估值报告）。两把尺子从不同方向指向同一事实——泡泡玛特是典型的"表外高资产化"公司。

桥接：130–325% 的经济资产化率让人惊讶——为什么极小的费用化投入能产生这么大的表外价值？答案藏在一种"凸性杠杆"机制里：每花 1 元设计费，撬动的是 39 元营收。

## 四、1:39 的凸性杠杆：设计费 9.51 亿如何撬动 371 亿营收

### 4.1 一个 1:39 的杠杆比

泡泡玛特 2025 年"设计及授权费"（孵化全部 IP 的总成本）仅 9.51 亿 RMB，占营收 2.6%（[B] 雪球 IP 列示 + [B] ebrun/新浪 授权费测算 + [S] 招股书）。这 9.51 亿撬动了 371 亿营收，杠杆比 ≈ 1:39（[S/B]）。

这是"极小费用化投入 → 极高表外 IP 价值"最直观的量化证据：在第三章用经济口径算出的 130–325% 资产化率，其物理来源正是这条 1:39 的杠杆。

### 4.2 塔勒布式凸性试错：下行封死、上行开放

杠杆为何能如此之高？招股书（[S]）披露的艺术家/IP 费支付结构给出了答案——"按销量付费、有年度上限"。这意味着：

- 下行封死：如果某个 IP 卖不动，公司只需支付固定的、有上限的保底，损失被锁在极小范围内；

- 上行开放：如果某个 IP（如 LABUBU）意外爆红，公司按销量付费，分成远低于爆款带来的边际利润，剩余收益几乎全部留在公司。

这是一种典型的塔勒布式"凸性试错"——用小的、可预测的成本，换取可能巨大的、不对称的收益。每孵化一个新 IP（如前述"一超多强"矩阵中 17 个过亿 IP），都是在用低固定成本博一个 LABUBU 级别的尾部事件。前述 THE MONSTERS 占营收 38.1% 的爆款，正是这种机制下产出的最大成果。

桥接：1:39 的凸性杠杆解释了"为什么是泡泡玛特"。但框架要成立，还需要回答"是不是只有泡泡玛特"——下面用 7 家公司做跨样本验证。

把"支出资产化率"框架铺到 7 家高品牌溢价公司，得到一个高度一致的模式（[S] 各公司 FY2024 财报 + [B] Brand Finance/Interbrand）：

共同指纹：会计口径全部落在 0.05%–3.7% 的极低区间，经济口径全部 >50%。泡泡玛特的 0.78%/130–325% 完全落在这个指纹带内——它不是孤例，而是"自创型品牌溢价者"的一个标准样本。

### 5.2 并购型反例：迪士尼与 LVMH

但样本里也有"不遵守"指纹的公司。迪士尼（[S] 10-K）记录的无形资产占总资产 42.9%，经济缺口的 89% 已通过并购入表；LVMH（[S] FY2024 年报）品牌无形资产占总资产 ~20%+。这两家的会计口径并不低。

它们为什么与众不同？答案在 Round 2 补强中浮现——决定因素不是"行业"，而是"自创 vs 并购"。迪士尼的 IP 多数通过收购（皮克斯、漫威、卢卡斯影业）获得，收购对价按公允价值入账，因此品牌价值大比例"上了表"；而 LVMH 旗下大量品牌同样靠并购积攒。

### 5.3 Hermès 的"证伪"：精修分界线

Round 2 还引入了一个关键对照样本——Hermès（[S] globenewswire / financialreports.eu）。作为同样属于奢侈品的自创品牌，Hermès 记录的无形资产仅 ~2.6%，与泡泡玛特同梯队。这一发现证伪了"行业决定论"（同样是奢侈品，并购型的 LVMH ~20%+，自创型的 Hermès 仅 2.6%），把分界线精修为"自创 vs 并购"。

通用代理指标因此可归纳为四条（[B] 数据平台）：
1. 会计口径 = 记录无形资产（剔除使用权资产/PP&E）/ 总资产；
2. 经济口径 =（市值 − 账面权益）/ 账面权益；
3. 品牌资产化效率 = 品牌价值 / 年 SG&A；
4. 指纹组合 = 高毛利 × 高 SG&A 费用化率 × 低记录无形资产。

桥接：跨公司验证让框架看起来相当稳健。但它有一个隐含前提——IP 必须长寿（经济口径里那 130% 的结构性下限，依赖 5 年以上的半衰期）。这个前提成立吗？2022 年发生的一件事，给出了第一次证伪。

## 六、转折：2022 年，高资产化率曾经塌缩过一次

### 6.1 一次几乎被遗忘的崩盘

2022 年，泡泡玛特股价较 2020 年高点跌去超过 90%（[B] 思想钢印 / 凤凰 / 证券时报 / 搜狐），同期毛利率 −4pct、归母净利 −49%，经营利润率回落到 12.6% 的低位（[S] westock 序列 + [B] 媒体）。

这组数据对框架构成了最直接的对抗证据——它证明"高资产化率"曾经塌缩过一次，第三章里那个 325% 的峰值，并不是稳定的常数。

### 6.2 长青率的冰冷数字：3.3%

更深层的对抗证据来自 IP 长青率：维基媒体 Top30 全球 IP 中，只有 Hello Kitty 一个是"形象 IP"，形象 IP 穿越周期的概率仅约 3.3%（[B] 中金全球 IP 生命周期复盘）。这与第三章半衰期敏感性分析里"5 年对应 130%"的下限相互呼应——潮玩 IP 的天然短周期，使经济资产化率必须乘以一个"可持续性折减"。

### 6.3 2025 的存货信号：风险侧已部分亮灯

把镜头拉回 2025 年末，能看到与 2022 相似但尚未爆发的早期信号（[S] 年报 + [B] 媒体）：

- 存货 54.73 亿 RMB（约 60.6 亿 HKD），同比 +258.9%，远超 184.7% 的营收增速；

- 存货周转天数从 101 天升至 122 天；

- 经营现金流 / 净利润从 1.59 降至 0.85；

- 卖空仓位升至流通股的 6.3%（2023.8 以来最高，[B] 证券时报）。

### 6.4 一个关键的细节：塌缩靠促销，而非减值

但 Round 2 核实发现了一个关键的细节差异（[S] 港股财务指标 2022）：2022 年泡泡玛特存货增至 8.67 亿 RMB、周转 160 天，但当年资产减值损失仅 9.3 万港元——近乎为零。

这意味着 2022 年的塌缩靠促销清库（牺牲利润）而非减值计提完成。换言之，存货减值在历史财报里始终是"前瞻风险"而非"已实现损失"——这也解释了为什么当前 54.73 亿存货虽让人警惕，却尚未在账面上引爆。

桥接：既然 2022 曾经塌缩过一次，当前的高资产化率到底是"结构性"的常态，还是又一次"峰值通胀"前的危险信号？这构成了最终判断的分水岭。

## 七、结构性还是峰值：什么证据改变判断？

### 7.1 同一公司、两种结论，两种稳健性

红队四问对核心结论做了压力测试（[S] + auditor 修正）。结论被拆成两条，它们的脆弱性截然不同：

||||
|---|---|---|
|A：泡泡玛特高经济资产化率（峰值上限 325%）|2/5（稳健）|多源 [S] 验证，方向无争议|
|B：泡泡玛特高经济资产化率是"护城河结构性成立"|4/5（脆弱）|依赖 LABUBU 集中度 + IP 半衰期，2022 已塌缩一次|

脆弱性 ≥4 必须显式讨论失败路径。

### 7.2 失败路径：三个条件同时成立

若以下三者同时成立，框架将从"护城河型"降级为"周期性资产"：

- LABUBU 退热（如前述 38.1% 占比快速回落）；

- 新 IP 接棒失败（如前述过亿 IP 矩阵无法再孵化出下一个头部）；

- 潮玩审美疲劳（如形象 IP 长青率 3.3% 的统计在泡泡玛特身上兑现）。

三者叠加时，EPV − AV 将从 987 亿压缩至 <400 亿（对应半衰期极短的 T 年情景），经济资产化率跌破 100%。

### 7.3 当前信号：已部分亮灯，但未达减值阈值

红队四问的逐条回答也指向同一判断（[S] + auditor）：

- 最弱证据：经济口径 325% 依赖 EPV − AV 代理 + 永续零增长假设；IP 半衰期无直接数据，靠类比任天堂推断；

- 最可能被推翻的环节：IP 半衰期假设——2022 年已被证伪一次（股价 −90%、毛利 −4pct）；

- 反方最强论证：第六章的 2022 塌缩 + 存货 +258.9% + LABUBU 峰值依赖 + 形象 IP 长青率仅 3.3% + 卖空仓位新高；

- 我方论证在哪失效：若把"峰值"误读为"结构性"，会把 325% 当成可持续值，忽略 130–180% 的真实区间。

当前真实状态是：存货 +258.9%、周转 122 天已部分亮灯，但尚未达到减值阈值——因此框架处于"风险侧偏向"，而非"已证伪"。

桥接：结构性还是峰值的分水岭已经清晰，最后一步是把所有变量收束成一个可执行、可证伪的量化判断。

## 八、综合研判

### 8.1 关键变量识别

- 正向变量（看什么判断对错）：IP 半衰期代理指标——THE MONSTERS 占比趋势 + 新 IP 接棒速度 + 存货周转天数。若占比下降且新 IP 占比上升、周转稳定，则经济资产化率为"结构性"。

- 逆向变量（什么翻转全盘皆输）：LABUBU 集中度 + IP 半衰期。若 THE MONSTERS 占比连续 >30% 且集团增速 <15%，或存货周转 >150 天并出现减值计提，则 325% 塌缩为"峰值通胀"，经济资产化率可能跌至 50% 以下（对应 T 年情景）。

- 交集变量（核心锚点/命门）：IP 集中度 / 半衰期——既是判断对错的正向指标，也是翻转全盘的风险变量。

### 8.2 因果链推演

A（费用化投入）→ B（表外 IP/品牌资产）→ C（EPV ≫ AV）→ 结论（高经济资产化率护城河型）

- A → B：每元费用化设计/营销投入，经艺术家生态的凸性杠杆，沉淀为自创 IP（9.51 亿撬 371 亿，1:39）。✅ 充分证据（[S] 年报费用性质 + [S] 招股书分成结构）。

- B → C：自创 IP 不入账（IAS 38），B/S 仅记 PP&E + 少量外购无形资产，而 EPV 捕获全部 IP 获利能力，故 EPV 1226 ≫ AV 239。✅ 充分证据（[S] KB 三要素 + Greenwald 框架）。

- C → 结论：EPV − AV = 987 亿 = 表外特许权，经济资产化率 325%。⚠️ 合理推测（依赖 EPV 永续零增长隐含"IP 近永久"；LABUBU 占 38.1% 使该值含峰值溢价）。

### 8.3 量化判断

- 会计口径 IP 资产化率：0.75%（RMB）/ 0.78%（HKD 原币口径）。

- 经济口径资产化率：130–325% 情景区间（结构性 130–180%，对应半衰期约 5–8.6 年；峰值上限 325%，[S/估算] 分母含 2010–19 粗估）。

- 表外占比（EPV 中）：80.5%。

- 维持条件：若 THE MONSTERS 占比降至 25% 以下，且新 IP Top3 合计 >40%，结构性经济资产化率可维持 ≥150%。

### 8.5 一句话总结

泡泡玛特以 0.78% 的会计口径与 130–325% 的经济口径，定量验证了"自创型品牌溢价者支出资产化率"框架——账面几乎不体现核心资产（表外 80.5%），但每元费用化投入以 1:39 凸性杠杆沉淀为表外 IP/品牌。结论稳健性取决于 IP 半衰期与 LABUBU 集中度：永续假设下 325% 落入任天堂–苹果梯队；但 2022 周期塌缩与存货激增提示该值偏"峰值上限"，结构性约 130–180%。框架对自创型成立，迪士尼/LVMH（并购型）为边界反例。
