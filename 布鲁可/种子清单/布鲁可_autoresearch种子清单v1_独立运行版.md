背景上下文：
布鲁可（00325.HK）是中国拼搭角色类玩具龙头，FY2025 营收 29.1 亿人民币。73 个授权 IP 中，变形金刚+奥特曼合计占角色收入 62%。关键风险：奥特曼授权 2027 年到期（圆谷），变形金刚 2028 年到期（孩之宝）。当前企业主页 N5 护城河置信度仅 !75%，N10 有条件收敛但 IP 续约是核心障碍。23 亿现金+零负债给了缓冲，但 IP 断崖可能导致收入断层 30-60%。需要系统评估续约概率、行业基准和替代可行性。

5. 最坏情景压力测试：两个头部 IP 同时丢失（概率低但非零），布鲁可 23 亿现金能撑多久？非授权 IP 收入（自有 IP+积木车+其他）的底仓是多少？

**为什么**：海外收入占比从 FY2025 的 11.0% 降至 26H1 的 8.3%。N10 三大支柱之一的"海外第二增长曲线"出现裂缝。如果海外增长故事证伪，N10 利润区间需大幅下修。

研究主题：布鲁可 26H1 海外收入降速的根因分析与 26H2 展望

研究深度：标准（3-5 维）

背景上下文：
布鲁可（00325.HK）FY2025 海外收入 3.19 亿人民币（占 11.0%），同比+397%，是 N10 收敛三大支柱之一。但 26H1 海外仅 1.11 亿（占 8.3%），年化推算全年海外可能同比下滑 20-30%。需要判断这是季节性波动（25H2 有黑五圣诞旺季）还是结构性降速（渠道铺货一次性效应消退/动销出问题）。

5. 26H2 展望——管理层对海外的最新指引？迪士尼系列（星球大战/蜘蛛侠/复仇者联盟）在海外上线的节奏和预期贡献？
