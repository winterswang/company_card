## 四、核心结论

PDD 是一家拥有确凿特许经营权的轻资产电商平台。 其盈利能力价值（$179/ADS 中枢）是资产重置价值（$92/ADS）的 1.95 倍，护城河溢价达 $87/ADS，来源于双边网络效应、算法推荐引擎和极致低价心智的三重壁垒。

当前股价 $84.85/ADS 仅相当于资产价值的 92%，提供了约 57% 的安全边际（vs 中枢 EPV）。这一深度折价主要反映三个市场担忧：① 中国国别风险（监管不确定性）；② 竞争格局恶化（抖音电商 GMV 已达 PDD 95%）；③ Temu 海外烧钱模式的可持续性。

成长溢价有限（~$18/ADS，EPV 的 10%），因为 EPV 的零增长标准化已"预支"了削减增长支出带来的利润率提升。PDD 的投资逻辑是 EPV 折价修复，而非成长性溢价。

## 附录：计算速查

AV = 74,877(表内) + 47,166(表外) + 14,716(非核心) − 770(债务) = 135,989 ($M)
标准化EBIT = 60,075 × 35.5% = 21,327 ($M)
NOPAT = 21,327 × (1-17%) = 17,701 ($M)
调整后盈利 = 17,701 + 417(D&A) − 50(维护CapEx) = 18,068 ($M)
EPV(企业) = 18,068 / 10% = 180,680 ($M)
EPV(股权) = 180,680 + 70,997(现金) + 14,716(非核心) − 770(债务) = 265,623 ($M)
EPV/ADS = 265,623 / 1,482 = $179.2
EPV/AV = 265,623 / 135,989 = 1.95 → 情境 C
成长价值 = EPV × 10% = $17.9/ADS
总内在价值 = $179.2 + $17.9 = $197.1/ADS
