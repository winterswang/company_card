用 kb-autoresearch 深度研究以下课题并归档到杨慎知识库。

研究主题：AppLovin AXON 引擎相对 Google AdMob/Meta Advantage+ 的广告匹配效率竞争优势及护城河半衰期评估

研究深度：深度（5-7维）

背景上下文：
AppLovin（APP.O）是一家移动广告技术平台公司，核心产品是AXON AI推荐引擎（2023H1推出2.0版本），通过AppDiscovery（广告主端）和MAX（流量端）连接广告主和发布商。FY2024收入47亿美元，净利率33.5%，软件平台EBITDA率78.2%。iOS游戏广告市占率第1（35%），Android第2（17%）。当前市值约$1,360亿（PE ~45-86x）。企业主页N5节点判断护城河半衰期为2-8年区间，这是全图最大认知缺口——如果半衰期只有2-3年，5-10年利润预测基础就不存在。AXON 2.0推出后广告收入从FY2022的10.5亿美元暴增至FY2024的约35亿美元，但Google和Meta同时在快速迭代AI广告产品（Advantage+/Performance Max）。

研究问题：
1. AXON引擎的技术架构（强化学习+深度学习）与Google Performance Max/Meta Advantage+的技术路径有何本质区别？各自的核心优势和弱点是什么？
2. AppLovin的广告ROAS（广告支出回报率）与Google AdMob/Meta的ROAS定量对比数据（如有第三方评测或广告主反馈）
3. 程序化广告行业历史上主要玩家的护城河半衰期（Criteo/IronSource/Unity Ads/Tapjoy/Vungle等），衰退的根本原因是什么？
4. AXON 2.0的效率提升有多少来自算法改进 vs 数据积累 vs ATT后的竞争清洗效应？
5. Google和Meta的AI广告产品在游戏广告垂直的渗透率和效率提升速度——它们能在多长时间内追平AXON？
6. AppLovin出售手游业务后，第一方数据来源的变化对AXON匹配精度的实质影响有多大？
7. 移动广告程序化购买的技术壁垒（实时竞价工程、oRTB协议、SDK集成深度）对护城河的贡献有多大？

已有 KB 材料（差分指引）：
- 广发证券AppLovin专题研究 -> 覆盖业务模式+产品矩阵+市场份额，但未深入AXON技术对比
- 华鑫证券Q3 2025点评 -> 覆盖最新季度财务数据，但无护城河分析
- APP.xlsx财务模型 -> 覆盖历史财务数据，无护城河维度
标注：autoresearch 0b KB预检应先 fetch 这些材料，避免重复搜索已知内容。

成功标准：
- 能给出AXON与Google/Meta的ROAS或转化率对比数据（即使是不完全的）
- 能量化程序化广告行业护城河半衰期的历史分布
- 能判断AXON优势在游戏广告垂直的可持续时间窗口（具体年数+理由）
- 能评估出售手游后第一方数据缺口的大小

研究主题：AppLovin CEO Adam Foroughi 的管理风格、制度化建设程度与继任风险

研究深度：标准（3-5维）

背景上下文：
AppLovin（APP.O）由Adam Foroughi（1980年生，伊朗裔美国人）于2012年创立。Foroughi持有Class C超级投票权股，内部人持股约23.2%，创始人个人是最大个人股东。关键战略决策（AXON 2.0 AI引擎投入、2025年出售手游业务聚焦广告）均呈现"CEO个人决策"特征。企业主页N7节点判断为"创始人-先知型"，N9节点判断为"报时型倾向"（竞争力绑定在个人身上），但这一判断因信息不足置信度为N。如果Foroughi突然离开，公司的战略连续性和AXON迭代节奏可能受到冲击。FY2024公司收入47亿美元，净利润15.8亿美元，同时进行大规模债务回购（发行46亿美元债务），内部人净卖出5.12亿美元+。

研究问题：
1. Foroughi的管理风格——是一人决策还是团队共识驱动？有没有系统性的决策流程和人才培养机制？
2. AppLovin的高管团队构成——CFO/CTO/VP Engineering等核心岗位的任期、背景和独立性如何？是否有内部培养vs外部空降的比例数据？
3. AXON引擎的研发团队规模、组织架构和决策机制——技术迭代是由CEO主导还是工程团队自主驱动？
4. Foroughi近年来的内部人交易模式——卖出规模、频率、是否与公司回购同步？是否存在利益错位信号？
5. 双重股权结构（Class C超级投票权）的治理风险——Foroughi即使出售经济利益仍保持控制权的潜在风险？

## 种子 C【Research · 高优先级】程序化广告行业护城河历史与AppLovin电商拓展可行性

N5护城河半衰期需要行业历史校准，N2/N5需要电商拓展数据验证定价权可持续性。

直接复制以下内容到新窗口：

---

用 kb-autoresearch 标准研究以下课题并归档到杨慎知识库。

研究主题：程序化广告行业护城河历史演变 + AppLovin电商广告拓展可行性评估

研究深度：标准（3-5维）

背景上下文：
AppLovin（APP.O）正在从游戏广告向电商广告拓展，2025年Q1电商广告年化运行率已达10亿美元（600+客户）。公司推出自助服务平台（2025年10月面向受邀客户，2026上半年全球推广）。企业主页判断N1为"平台收税者+网络飞轮者"，但电商广告是Google/Meta的主场，AppLovin能否在非游戏垂直复制AXON的效率优势是核心疑问。同时，程序化广告行业有过多次"明星崛起后快速衰落"的案例（Criteo重定向广告衰退、IronSource被收购后表现不佳），需要历史校准来判断AppLovin护城河的持久性。

研究问题：
1. 程序化广告行业过去10年的主要玩家（Criteo/Tapjoy/Vungle/IronSource/Unity Ads/Mintegral等）的兴衰轨迹——护城河形成和衰退的根本原因是什么？
2. AppLovin电商广告的实际ROAS数据——与Google Shopping/Meta Advantage+ Shopping相比如何？广告主反馈和留存率如何？
3. 自助服务平台对广告主规模扩张的影响——历史上其他广告平台（如Trade Desk、Google Ads）推出自助服务后的客户增长曲线？
4. 电商广告与游戏广告在数据维度和匹配逻辑上的差异——AXON的算法是否需要根本性调整才能在电商领域达到同等效率？
5. 全球数字广告市场中AppLovin可寻址空间的测算——游戏广告+电商广告+CTV广告的TAM分别是多少？

已有 KB 材料（差分指引）：
- 广发证券专题研究 -> 覆盖电商试点初步数据（24Q3试点ROI超预期），但数据较旧
- 浦银国际报告 -> 覆盖电商广告年化运行率10亿美元+600客户，但无竞品对比
标注：autoresearch 0b KB预检应先 fetch 这些材料。

成功标准：
- 能量化程序化广告行业护城河半衰期的历史分布和衰退模式
- 能给出AppLovin电商广告的ROAS/客户留存数据或代理指标
- 能判断AXON在电商垂直的效率是否接近游戏垂直水平
