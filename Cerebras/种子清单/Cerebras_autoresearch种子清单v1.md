研究深度：标准(3-5维)

背景上下文：
Cerebras Systems（CBRS）与 OpenAI 签署了 $200 亿+多年期算力采购合同（750MW，可扩至 1.25GW），是 Cerebras 未来 2-3 年 ~90% 预期收入的来源。此外 OpenAI 还提供了 $10 亿贷款（年利率 6%）和 3,340 万认股权证（行权价 $0.00001/股），形成客户+债权人+潜在股东的三重绑定。企业主页 N2（定价权）和 N10（稳定利润可估性）均标注此合同条款不透明为核心认知缺口。当前 Core 毛利率 Q1 FY2026 为 46.5% 但 Q2 指引骤降至 36-38%。FY2025 营收 $5.10 亿，客户集中度 86%（前两大：MBZUAI 62% + G42 24%）。

研究问题：
1. OpenAI 合同的收入确认机制是什么？（按 MW 部署确认 vs 按使用量确认 vs 按里程碑确认？）
2. 合同中是否包含定价折扣条款（量大折扣/年度降价/最惠国条款）？这如何影响边际毛利率？
3. 合同的产能里程碑要求是什么？（Cerebras 需要在什么时间点交付多少 MW？未达标的后果是什么？）
4. 合同的终止条件和退出条款是什么？（OpenAI 能否在什么条件下退出？违约金安排？）
5. OpenAI 三重绑定（客户+债权人+股东）的利益冲突如何影响合同公平性？有无独立董事审查证据？

研究主题：Cerebras WSE-4/CS-4 推理性能基准测试数据与竞品对比

研究深度：快速(2-3维)

背景上下文：
Cerebras 的核心护城河是晶圆级芯片在低 batch 推理场景的性能优势。WSE-3 vs H100 的推理倍率为 7.4x（Llama 3.1 8B，1,800+ tok/s vs 243 tok/s）。WSE-4 已发布（SRAM 从 44GB 升至 128GB，+191%），但实测推理倍率数据尚未出现。企业主页 N5（护城河半衰期）标注此为核心认知缺口——如果 WSE-4 倍率显著低于 WSE-3 的 7.4x（如 <5x），说明优势正在收敛，护城河半衰期需缩短。同时需关注 Nvidia Rubin（2026 Q3 量产）和 Groq LPU（已被 Nvidia 收购，128GB SRAM）的推理性能数据，判断竞争差距变化方向。

研究问题：
1. WSE-4/CS-4 是否有已发布的基准测试数据？如有，推理吞吐和延迟 vs WSE-3 和 vs Nvidia Blackwell（B200）的倍率是多少？
2. WSE-4 的 SRAM 128GB 增长是否解决了上下文窗口限制（WSE-3 仅 128K tokens）？agentic workflow 的中位请求是否仍在服务能力范围内？
3. Groq LPU（256 LPU/托盘，128GB SRAM，640TB/s 带宽）的推理性能 vs Cerebras WSE-3/WSE-4 的对比数据？
